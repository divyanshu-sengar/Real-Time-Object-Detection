## 📌 About the Project

A real-time object detection application built using Python, a pretrained YOLO model, and OpenCV. It captures webcam frames, detects everyday objects, and displays bounding boxes and labels.

## ✨ Features

- 🎥 Live webcam object detection
- 🤖 Pretrained YOLO model
- 📦 Bounding boxes and object labels
- 🎯 Configurable confidence threshold
- ⚡ Continuous frame processing
- 🛑 Press `Q` to exit

## 🛠️ Technologies

- Python
- Ultralytics YOLO
- OpenCV
- Computer Vision

## ▶️ How to Run

Install the required libraries:

```bash
pip install ultralytics opencv-python
```

Run the application:

```bash
python main.py
```

Make sure your webcam is connected. The model weights may download automatically on the first run.
